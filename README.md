# Круглый купол Носарева площадью 6 м²

Связанный расчёт OpenFOAM и деформируемой оболочки. Купол круглый в раскрое, с закрытым полюсом и проницаемой тканью. Длина строп равна раскройному диаметру, скорость потока 30 м/с. Ось купола выставляется на заданный угол перед каждым проходом CFD. Ткань деформируется под действием давления и нагрузок от строп.

Для расчёта нужны Linux, Slurm, модуль OpenFOAM `openfoam/2212` с MPI и компилятором для динамического кода, а также Python 3.9 или новее с NumPy и Matplotlib. Список Python-зависимостей хранится в `requirements.txt`. Словари расчётной области и начальную геометрию создаёт код в `coupled/`.

## Запуск

Из корня репозитория на кластере:

```bash
sbatch cluster/nos6_held.slurm 3.2 24
```

Первый аргумент — диаметр стропы в миллиметрах. Значение `3.2` используется как пробное и не подтверждено для опыта Носарева с куполом 6 м². Второй аргумент — число строп, по умолчанию 24. При переданном диаметре сопротивление строп учитывается в потоке и переносится на узлы оболочки. Для равномерного расположения точек крепления скрипт при необходимости увеличивает число узлов по окружности.

По умолчанию запускаются десять углов от 0° до 45° с шагом 5°, до двух заданий одновременно. Для одного расчёта при 30°:

```bash
sbatch --array=6 cluster/nos6_held.slurm 3.2 24
```

Если нужные Python-библиотеки установлены в отдельном окружении, перед запуском задай `NOS6_PYTHON` полным путём к его интерпретатору. По умолчанию используется `python3`. Имя модуля OpenFOAM можно переопределить переменной `NOS6_OPENFOAM_MODULE`. Раздел и число процессов задаются параметрами Slurm.

## Результаты

Каждый угол получает папку `run/nos6held/<номер массива>/aXX/`. В `out/` сохраняются журнал и коэффициенты по проходам. Вклад строп в аэродинамические коэффициенты записывается отдельно. После последнего завершённого прохода `pics/` содержит рисунки и `parachute.stl` с куполом и стропами после релаксации. Карты давления относятся к геометрии последнего прохода CFD.
