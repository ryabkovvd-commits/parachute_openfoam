# Разложение отрицательного момента: текущий результат и следующая проверка

Для фиксированного случая 9014 (форма inner, сетка из 9010/inner/m1.25,
981214 ячеек, 200 CFD-итераций) пользователь передал:

- покрытие парными гранями 100%, непарных граней нет;
- максимальное расстояние между центрами граней в VTP равно нулю;
- момент давления по CFD-граням My = -1042.16368 Н·м;
- момент перенесённых узловых сил My = -1042.52757 Н·м;
- относительное различие суммарных сил при переносе 2.51e-15;
- изменение момента при переносе -0.36389 Н·м, около 0.035% его модуля.

Следовательно, в этом случае отрицательный знак существует до переноса
нагрузки на структурную сетку. Ошибка парности и неточность переноса не
объясняют знак в принятом расчёте. Стропная добавка также не создаёт его:
момент давления самого купола уже отрицателен.

Восемь участков купола дают:

| Половина по геометрической координате x′ | Суммарный вклад в mz | Момент давления, Н·м |
|---|---|---|
| x′ < 0 | -0.23982641 | -2192.439 |
| x′ ≥ 0 | +0.12582627 | +1150.275 |
| Весь купол | -0.11400014 | -1042.164 |

Отношение модулей вкладов около 1.91. Координата x′ определяется
вектором (cos(alpha), 0, -sin(alpha)) относительно центра кромки;
она не является глобальной координатой X или координатой из опыта
Носарева без дополнительного согласования.

В четырёх отрицательных полосах средний deltaCp около 1.24–1.26;
на положительной стороне он уменьшается до 0.43 у края.
Один перепад давления не определяет знак момента: нужны также нормаль
нагруженной грани и её плечо относительно коуша.

## Расширенная постобработка без нового CFD

Перенести только обновлённый coupled/aero_diagnostics.py.
Существующая команда обработки остаётся:

    export NOS6_PYTHON=/home/016/apps/dashboard/anaconda3/bin/python
    W=run/fixed_mesh_check/9014
    "$NOS6_PYTHON" coupled/nos6_results.py pressure "$W" --speed=30
    cat "$W/out/moment_halves_pass01.csv"

Новая компактная таблица содержит две строки. Cp_master и Cp_slave —
средние по площади давления на двух именованных берегах ткани,
нормированные на V²/2 для кинематического поля давления p.
Используется нулевой уровень давления из CFD-постановки.
Названия patch сами по себе не доказывают классификацию «внутри/снаружи»
в области складок.

Составляющие момента:

    dmz_zFx       = sum((z-z_anchor) * dFx) / (q*S0*D0)
    dmz_minus_xFz = -sum((x-x_anchor) * dFz) / (q*S0*D0)
    dmz          = dmz_zFx + dmz_minus_xFz

Момент приводится к общему узлу строп, положительная ось +Y.
Таблица moment_bands_pass01.csv сохраняет прежние первые восемь столбцов,
после них добавлены Cp_master, Cp_slave и две составляющие момента.
В JSON добавлено глобальное разложение по согласованным парам.

Рисунок pics/moment_pressure_terms.png показывает давления двух берегов
и два вклада в момент по тем же восьми полосам.
Прежний moment_contributions.png сохраняет смысл суммарного момента.
Стропы и вязкая тяга в этих таблицах давления не включены.
Количество согласованных граней и долю площади следует проверять отдельно.

По этой таблице можно отличить слабый перепад давления от компенсации
двух больших моментов. Для установления физической причины распределения
давления нужны независимые проверки модели ткани и сопоставление
со стенкой при одинаковой геометрии. Эта обработка сама по себе
не доказывает корректность закона ткани, касательного условия,
формообразования или соответствие экспериментальному держателю.
