# Уточнение моментной характеристики непроницаемого купола при 45–50°

Из корня кластерного проекта после переноса обновлённого `cluster/`:

```bash
export NOS6_PYTHON=/home/016/apps/dashboard/anaconda3/bin/python
bash -n cluster/nos6_wall_refine.slurm
sbatch cluster/nos6_wall_refine.slurm
```

Массив содержит шесть углов: 45, 46, 47, 48, 49 и 50°. Четыре промежуточных
угла новые; 45 и 50° повторяются как контроль сопоставимости с серией 8928.
Одновременно выполняются две задачи, каждая запрашивает один узел и 36 MPI-процессов
в разделе `compute1` на срок до двух суток. Каждый случай начинает расчёт с
преднаполнения; архивные формы соседних углов не используются как затравки.

Постановка: непроницаемая оболочка, площадь 6 м², закрытый полюс, 24 стропы,
длина строп равна номинальному диаметру, диаметр строп 3,2 мм, Cd=1,2,
структурное разбиение 96×12, V=30 м/с, nu=1,46e−5 м²/с. Удержание `legacy`,
исходная ограниченная схема градиента давления; модели проницаемости и
режим `inner` не включаются. `--сдвиг=0.02` задаёт долю сдвиговой жёсткости,
а `--shape-tol=0.03` — отдельный порог изменения формы.

Задаются 2000 SIMPLE-итераций на CFD-проход и 12 полных внешних проходов
(`--all-passes`). Ранняя остановка отключена, чтобы сохранить более длинную
историю момента. Число проходов и итераций не является доказательством
сходимости. После расчёта нужно отдельно сравнить изменения Cx, Cy и mz
на последних проходах и историю момента внутри CFD.

Результаты записываются в:

```text
run/nos6wall_refine/НОМЕР_МАССИВА/a45
...
run/nos6wall_refine/НОМЕР_МАССИВА/a50
```

Архив `run/nos6wall/8928` не изменяется. В каждый новый случай копируется
установленный каталог `coupled/`, затем сохраняется `source_sha256.json`.
Поэтому последующее обновление общей папки не меняет код уже начавшегося случая.
Повторный запуск в существующий каталог угла останавливается. При обновлении
самих вычислительных модулей повторные 45/50° позволяют проверить сопоставимость;
одинаковый набор физических параметров не гарантирует побитового повторения
старого расчёта.

Проверка результатов после завершения, где JOB — фактический номер массива:

```bash
JOB=12345
for A in 45 46 47 48 49 50; do
  W="run/nos6wall_refine/$JOB/a$A"
  echo "$W"
  tail -n 8 "$W/out/nos6_held.txt"
done
```

Знак момента сравнивается в одной системе координат. В выводе старого профиля
`mz` — момент по +Y; при переходе к скоростным осям Носарева он соответствует
моменту по +z и сохраняет знак. Поперечный коэффициент меняет знак.

До получения результатов утверждается только существующая смена знака между
45 и 50°. Значения промежуточных углов и точный угол нулевого момента не
подставляются из интерполяции как результаты расчёта.
