# Контрольный расчёт: влияние grad(p) на момент

## Основание

Пользователь передал операторный аудит трёх случаев серии 8996. Ниже приведены округлённые значения коэффициентов момента интегральных операторов:

| Вариант | Клеточный остаток | Поверхностное давление минус объёмный grad(p) | Ограниченный grad(p) минус Gauss | Конвективный зазор | Вязкий зазор |
|---|---:|---:|---:|---:|---:|
| df | −0,0007017 | −0,09936 | +0,09933 | −0,02645 | −0,001942 |
| darcy | −0,002179 | −0,07727 | +0,07724 | −0,01120 | −0,001239 |
| quadratic | +0,0002238 | −0,09306 | +0,09303 | −0,03097 | −0,002262 |

На давление приходится ориентировочно 74–84% реконструированной поверхностной невязки момента. Этот вклад почти полностью связан с различием ограниченного и гауссова градиентов на сохранённом поле. Остаток непосредственно клеточного уравнения значительно меньше поверхностного остатка, но его малость не является доказательством локальной сходимости всех полей.

В исходной постановке записано:

```text
gradSchemes { default cellLimited Gauss linear 1; }
```

Поэтому ограничитель применяется и к давлению. `cellLimited` масштабирует градиент для ограничения экстраполированных значений на гранях; описание приведено в [документации OpenFOAM](https://doc.openfoam.com/2306/tools/processing/numerics/schemes/gradient/rtm/cellLimited/).

Декомпозиция локализует численный источник большей части незамыкания. Она **не позволяет прибавить +0,09933 к исходному аэродинамическому моменту**: изменение схемы меняет всё решение потока. Знак нового момента и степень улучшения баланса устанавливаются отдельным расчётом. Конвективный и вязкий зазоры также остаются предметом проверки.

## Что изменяется в контрольном случае

Добавляется только именованная схема:

```text
gradSchemes
{
    default cellLimited Gauss linear 1;
    grad(p) Gauss linear;
}
```

Общая форма, точная CFD-сетка, угол 30°, скорость 30 м/с, вязкость, ткань `33.2,28.6`, стропы, турбулентность, остальные схемы и 2000 итераций сохраняются. Начальная инициализация повторяет исходную продувку; поля итерации 2000 не используются как новая затравка. Исследуется одна фиксированная форма, без структурной релаксации.

`cs.py` поддерживает `--pressure-gradient=gauss` и `--pressure-gradient=default`. Без нового ключа сохраняется прежняя схема. Выбор записывается в историю прохода и выводится в журнале.

Сценарий `permeability_models.slurm` повторно использует общую подготовку по `model.json` исходного случая. Путь к `setup` извлекается автоматически. Он сохраняет ссылку `baseline_case`, проверяет исходную форму и сетку и после CFD требует, чтобы весь `fvSchemes` отличался от исходного только указанной вставкой. Дополнительно сравниваются `fvSolution`, параметры среды и турбулентности, геометрия строп, `fvOptions` и физические параметры истории. Исходная серия не перезаписывается.

## Минимальный перенос и запуск

Обновить два файла:

- `coupled/cs.py`;
- `cluster/permeability_models.slurm`.

Текущие `momentum_balance.py`, C++-аудит и прочие зависимости должны уже соответствовать операторной версии, которая выдала строки `operators` для 8996. Сценарий использует установленный `nos6MomentumAudit` из того же OpenFOAM-окружения. Если исполняемый файл отсутствует, запуск останавливается до CFD; сначала нужно собрать инструмент штатным сценарием аудита.

Из корня `porousDisk_bundle`:

```bash
export NOS6_PYTHON=/home/016/apps/dashboard/anaconda3/bin/python
JPG=$(sbatch --parsable --array=0 --job-name=perm_pgrad cluster/permeability_models.slurm run/permeability_models/8996/df gauss)
JPG=${JPG%%;*}
printf 'Job: %s\n' "$JPG"
squeue -r -j "$JPG"
```

`--array=0` выбирает только действующий двухчленный закон `df`. Запрашивается один узел с 72 MPI-процессами, как у исходного расчёта. Явного запроса памяти нет. Новый каталог: `run/permeability_models/JOB/df`.

После CFD автоматически выполняются проверка формы и сетки, проверка различий `fvSchemes`, аудит нового `df` и стандартная постобработка с рисунками/STL. На этом этапе другие законы не пересчитываются. Для режима без изменения градиента прежняя форма вызова с `manifest.json` остаётся доступной.

После завершения:

```bash
tail -n 8 "run/permeability_models/$JPG/df/out/nos6_held.txt"
grep -E 'Checked:|df: mz_p|operators df:|Q canopy' "perm_pgrad-${JPG}_0.out"
```

При сбое нужно смотреть полный `perm_pgrad-JOB_0.out` и журналы `case/log.*` нового случая. Отсутствие строки `Checked: only grad(p) changed in fvSchemes` не подтверждает корректность контрольной постановки.

## Сопоставление результатов

Исходные АДХ `8996/df`: `Cx=0.5448040583`, `Cy=0.2105788864`, `mz=-0.0855651838`, `K=0.3865222427`. Сравниваются новые АДХ, расход ткани, история сил, поверхностный остаток, клеточный остаток, вклад ограничителя и конвективный зазор.

Нужно установить, уменьшается ли давление-градиентная часть невязки после действительного решения с `Gauss linear` и как меняется момент. Совпадение знака с экспериментом само по себе не заменяет проверки баланса, сходимости и закона ткани. Исходные расчёты сохраняются как результаты прежней численной схемы.

Проверены формирование обеих конфигураций, неизменность остальных схем и отказ при посторонних изменениях `fvSchemes`. Контрольный CFD-случай этой версии на кластере ещё не запускался по имеющимся подтверждениям.
